# Security

Report a vulnerability privately through [GitHub's private vulnerability reporting](https://github.com/NotAisu/Accessibility_Extension/security/advisories/new), not in a public issue. You get an answer within a week.

Security fixes go into the latest release.

## What Allyproof does with your code

- The Check parses your files with bundled engines and configs. It never executes your project's code or loads its lint config.
- Nothing is sent anywhere unless you start an AI Review. AI Review sends code only to the provider you chose.
- The command line makes no network requests.

Command Line (Node 24.15+)

Check an entire repo, staged Git files, or a PR diff with text, JSON, or SARIF 2.1.0 output and baselining for legacy codebases.

npx allyproof check .

Also: --staged, --changed origin/main --format sarif, baseline, explain

Local stdio MCP for Coding Agents

Offline, read-only MCP server with check (files, folders, or proposed code before writing), explain_rule, list_rules, and the allyproof_review prompt.

npx -y allyproof@0.2.0 mcp

Works with Claude Code, Cursor, Codex, VS Code, Windsurf, Cline, Roo Code, Zed, and Gemini CLI.

Verify everything yourself.

Every commit runs the full accuracy suite on both source and unpacked release bundles. You can also benchmark how your own coding agent performs with and without Allyproof locally.

npm run bundle
npm run eval:agent -- --dry-run --limit 1
npm run eval:agent -- --claude sonnet --limit 1

The evaluation harness scores fixed Findings, fails immediately on any newly introduced regression or deleted content, verifies claim honesty against the Check, and writes token and time metrics to out/agent-eval/report.json. Machine-readable setup metadata for AI agents is published at llms.txt.

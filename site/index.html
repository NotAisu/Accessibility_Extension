Only Proven rules block your build

Static accessibility linters lose developer trust when they cry wolf. Allyproof enforces ADR 0005: a rule earns blocking status per language only after clearing an independent statistical precision gate.

Proven Finding

73 Proven rules at 100% measured precision

Verified independently per language across HTML, JSX, TSX, Vue, Svelte, Angular, and Astro using W3C ACT Rules test cases, labelled real open-source components, and single-failure injections.

Every Proven rule meets a ≥ 95% Wilson lower confidence bound at 95% confidence (6,092 of 6,092 cases correct, 0 false positives in src/core/proof-status.json).

Needs Review

Honest visibility instead of silent passes

Unproven rules and runtime-only criteria — such as rendered text contrast (1.4.3), non-text contrast (1.4.11), and 24×24 CSS px target size (2.5.8) — are never fabricated from class names or silently marked passing.

They appear under Needs Review for a human or an agent with a browser tool using the optional skills/allyproof-browser-audit/SKILL.md workflow.

100% local, offline, and zero workspace code execution

Built so you can run Allyproof on proprietary codebases and untrusted pull requests without leaking source code or executing repository configs.

Zero telemetry, zero accounts

Allyproof collects nothing and phones home never. This documentation site itself loads zero JavaScript, zero analytics, and zero external subresources.

Offline deterministic Check

The VS Code extension Check, npm CLI, GitHub Action, and local stdio MCP server make zero network requests and run no AI.

Static parsing only

Your source files are parsed as data and never executed. Your repository's ESLint, TypeScript, or framework configs are never loaded or run (ADR 0002).

Explicit, bounded AI Review

In VS Code, AI Review is opt-in and runs only on demand with GitHub Copilot or a local OpenAI-compatible server (LM Studio / Ollama). Untrusted workspaces lock down local endpoint settings.

Reproducible ground truth and agent evaluation

Allyproof separates deterministic CI verification (which runs on every commit against source, VSIX, and npm bundles) from local LLM agent evaluations (which run on demand with your chosen model).

npm run bundle
npm run eval:agent -- --dry-run --limit 1
npm run eval:agent -- --claude sonnet --limit 1
  • Fixed FindingsCounts labelled ground-truth Findings the Check no longer reports after the edit.
  • Zero regressionsAny new Finding introduced by the agent's edit fails the run immediately.
  • File integrityThe file must still parse and preserve visible text and interactive elements (deleting markup to silence a rule fails).
  • Claim honesty & costEvery claimed fix must match a real before/after Check delta; tool calls, tokens, and wall time are recorded in out/agent-eval/report.json.

Because eval:agent depends on your chosen model and tokens, it is never run in CI and this page publishes no synthetic or unverified LLM benchmark numbers. Machine-readable agent metadata is available at llms.txt.
